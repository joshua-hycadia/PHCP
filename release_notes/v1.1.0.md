PHCP 1.1.0 - Perl Hydraulic Calculation Program

A Hardy Cross loop-balancing hydraulic solver for fire sprinkler and hydrant systems: a plain-text command language for the model (`.phc`), an editor built around it, a calculation report in ASCII text or PDF, and an AutoCAD exporter. Australian units by default (L/min, kPa, m, mm).

## Downloads

| file | what it is |
|---|---|
| `phcp_editor.exe` | the editor: write the model, VALIDATE (F4), CALCULATE (F5), WRITE REPORT (Ctrl+R) |
| `phcp.exe` | the command line: `phcp.exe model.phc report.pdf`, or `phcp.exe --json model.phc` for another program |

Both are self-contained Windows programs with the pipe and fitting database and the report typeface packed inside. They replace the 1.0.0 files in place; nothing else needs to change.

## What changed since 1.0.0

- **Orifice plates (`OPP`, `OFD`): a CD given now counts.** The plate's differential is 633.28 (0.596/CD)^2 (Q^2/d^4)(1-b^4), i.e. it scales as 1/CD^2. In 1.0.0 a CD changed only the ISO 5167 permanent-loss ratio, because the constant already held CD 0.596. `OPP` sizes through the same formula, so it follows. A CD of 0 or less, or above 1, is refused on its line.
  **Results change only where a CD other than 0.596 is given.** Every example solves exactly as before. A 1.0.0 calculation with a CD on an orifice plate should be re-run.
- **The PHCP icon.** The editor now shows it on its window and taskbar button on Windows; 1.0.0 showed Tk's. Both `.exe` files now show it in Explorer; 1.0.0 showed the packager's. Every build reads the icon back out of each `.exe` and compares it with `data/phcp.ico` (`tools/check_exe_icon.pl`), and CI does the same as Windows shows it.
- **A 300-model benchmark** against other calculation programs, in `comparison/` in the source download. It adds files only and changes no solved number.

## Known limits

- The AutoCAD commands (PHCPEXPORT, PHCPSOLVE) have been checked for structure but not yet run inside AutoCAD.
- A 1000-node gridded network takes several minutes to solve. A design area of a few hundred nodes solves in seconds.
- AS 1074 Medium as the basis bore for AS 2118.1 Table 14.11.1 is an assumption; the Standard does not state one. The database is user-editable, and a changed value is only as good as its source.
