PHCP 2.0.0 - Python Hydraulic Calculation Program

A Hardy Cross loop-balancing hydraulic solver for fire sprinkler and hydrant systems: a plain-text command language for the model (`.phc`), three windows on that one engine, a calculation report in ASCII text or PDF, an AutoCAD exporter and a pyRevit extension. Australian units by default (L/min, kPa, m, mm).

**PHCP is now written in Python.** 1.6.0 was the last Perl release. The engine, the command line, the report and the PDF, sizing, design areas, QUICK TOOLS, the database editor, the three windows and the Windows packaging are ported from the Perl, function by function, and judged against 1.6.0 byte for byte.

## Downloads

| file | what it is |
|---|---|
| `phcp_editor.exe` | the text editor: write the model, VALIDATE (F4), CALCULATE (F5), WRITE REPORT (Ctrl+R) |
| `phcp_sheet.exe` | the spreadsheet: the same `.phc` file and the same engine, entered as a sheet |
| `phcp_isometric.exe` | the same calculation, drawn on an isometric grid |
| `phcp.exe` | the command line: `phcp.exe model.phc report.pdf`, `phcp.exe --save model.phc`, `phcp.exe --json model.phc`, or `--strict` to exit 0 for ACCEPTED only |
| `PHCP_User_Guide.pdf` / `.docx` | the user guide, with pictures of the three windows |
| `PHCP_Reference_Manual.pdf` / `.docx` | the `.phc` command reference |

The four programs are self-contained Windows programs (PyInstaller) with the pipe and fitting database and the report typeface packed inside. They replace the 1.6.0 files in place. An office copy of the database in `data\pipes.dat` beside the programs still wins over the packed one, and the settings file is unchanged.

## What changed since 1.6.0

- **The language of the program**, and nothing a user sees: the same `.phc` files, the same commands, the same solved flows and pressures, the same report, the same JSON (interface 2), the same results block saved by `--save`, the same exit statuses.
- **The name**: the banner, the report cover and the supply graph sheet say "Python Hydraulic Calculation Program", and the version is 2.0.0.
- **Running from source** needs Python 3.10 or later (tkinter for the windows); nothing else. Perl is no longer needed.
- **The Revit extension**: the ENGINE button takes `phcp.exe`, or the Python `phcp` from a source folder, which is run with Python.

## Verified

The Python against PHCP 1.6.0 (Perl), by `tools/compare_perl.py`: the text output, the JSON, the full text report, the `--save` results block and the exit status of each model. The program's name and version, the solve's time to the minute and the results block's CHECK hash (which covers the version) are the only differences set aside.

| check | result |
|---|---|
| comparison sets (900 models: round 1, and round 2 with fittings and with devices), text + JSON + exit status, against 1.6.0 | 900 / 900 identical |
| examples, text, JSON, report, `--save`, `--strict`, against 1.6.0 | 10 / 10 identical |
| the command line's error paths (usage, unreadable and unwritable files, non-.phc files, standard input) | identical messages and exit statuses |
| models with Latin-1 or UTF-8 text, and with CRLF line endings | identical |
