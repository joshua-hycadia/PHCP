PHCP 1.3.0 - Perl Hydraulic Calculation Program

A Hardy Cross loop-balancing hydraulic solver for fire sprinkler and hydrant systems: a plain-text command language for the model (`.phc`), three windows on that one engine, a calculation report in ASCII text or PDF, an AutoCAD exporter and a pyRevit extension. Australian units by default (L/min, kPa, m, mm).

## Downloads

| file | what it is |
|---|---|
| `phcp_editor.exe` | the text editor: write the model, VALIDATE (F4), CALCULATE (F5), WRITE REPORT (Ctrl+R) |
| `phcp_sheet.exe` | the spreadsheet: the same `.phc` file and the same engine, entered as a sheet |
| `phcp_isometric.exe` | the same calculation, drawn on an isometric grid |
| `phcp.exe` | the command line: `phcp.exe model.phc report.pdf`, or `phcp.exe --json model.phc` for another program |

All four are self-contained Windows programs with the pipe and fitting database and the report typeface packed inside. `phcp.exe` and `phcp_editor.exe` replace the 1.2.0 files in place.

## What changed since 1.2.0

- **The solver, the report and the database are unchanged.** Every 1.2.0 result is the same in 1.3.0.
- **Spreadsheet window** (`phcp_sheet.exe`). It reads and writes the same `.phc`. It has lookups, row editing, completion of pipe type, diameter and node type, and an orifice plate tab sized by the solver.
- **Isometric window** (`phcp_isometric.exe`). It draws the solved network on an isometric grid, and a named grid is drawn as that grid.
- **One palette and one set of type** across the three windows. Each has its own dark mode, remembered as EDITOR_THEME, SHEET_THEME and ISO_THEME.
- **pyRevit extension** (`revit/PHCP.extension`, Revit 2022 to 2027). It walks the model, writes a `.phc` and runs `phcp.exe --json`, with outlet, device, review, SUGGEST and APPLY commands. See `revit/REVIT.md`.
- **Icon** redrawn so that both loops stay readable at 16 pixels.
- **Removed:** the drawn network and fast entry. The isometric window and the spreadsheet replace them.

## Known limits

- The pyRevit extension has been checked without Revit (`tools/test_revit.py`) but not yet run inside Revit.
- The AutoCAD commands (PHCPEXPORT, PHCPSOLVE) have been checked for structure but not yet run inside AutoCAD.
- A 1000-node gridded network (example 04) takes about 35 minutes to solve. A design area of a few hundred nodes solves in seconds.
- AS 1074 Medium as the basis bore for AS 2118.1 Table 14.11.1 is an assumption; the Standard does not state one.
