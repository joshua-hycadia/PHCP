PHCP 1.2.0 - Perl Hydraulic Calculation Program

A Hardy Cross loop-balancing hydraulic solver for fire sprinkler and hydrant systems: a plain-text command language for the model (`.phc`), an editor built around it, a calculation report in ASCII text or PDF, and an AutoCAD exporter. Australian units by default (L/min, kPa, m, mm).

## Downloads

| file | what it is |
|---|---|
| `phcp_editor.exe` | the editor: write the model, VALIDATE (F4), CALCULATE (F5), WRITE REPORT (Ctrl+R) |
| `phcp.exe` | the command line: `phcp.exe model.phc report.pdf`, or `phcp.exe --json model.phc` for another program |

Both are self-contained Windows programs with the pipe and fitting database and the report typeface packed inside. They replace the 1.1.0 files in place; nothing else needs to change.

## What changed since 1.1.0

- **Velocity pressure, as an option (`OPTION VELOCITY_PRESSURE ON|OFF`; VELOCITY PRESSURE in the editor's PROJECT tab).** **Default OFF: every existing result is unchanged.**
  - With ON, in-line sprinklers discharge on the normal pressure, q = K sqrt(Pt - Pv), with Pv = rho v^2 / 2 in the pipe bringing the most water into the head's node. This is AS 2118.1:2017 Clause 14.15, at the designer's discretion, and applies to range pipes and distribution mains alike.
  - End sprinklers, hydrants, hose reels and fixed flows stay on total pressure, as do friction, elevation and node pressures.
  - The report (cover sheet, Sections 1, 4, 7 and 8), the JSON (`velocity_pressure`, and per outlet `velocity_pressure` and `discharge_pressure`; interface still 1) and the editor all state which basis was used.
  - The rule is in `docs/PHC_REFERENCE.md` 5.5.1.
- **Example 04** (the 1000-node grid) now sets `OPTION MAXITER 30000`. The grid needs 24 820 iterations, so the old 20000 stopped it short. Only the example file changes; no other example moves.
- **Benchmark round 2**, in `comparison/ROUND2.md` in the source download, repeats the 300 networks with fittings, and with a BFP, a fixed-drop PRV and an orifice plate. It adds files only and changes no solved number.

## Known limits

- The AutoCAD commands (PHCPEXPORT, PHCPSOLVE) have been checked for structure but not yet run inside AutoCAD.
- A 1000-node gridded network (example 04) takes about 35 minutes to solve: 24 820 Hardy Cross iterations, each one traceable. A design area of a few hundred nodes solves in seconds; with devices, a gridded system of 150 or more heads can take tens of minutes.
- AS 1074 Medium as the basis bore for AS 2118.1 Table 14.11.1 is an assumption; the Standard does not state one. The database is user-editable, and a changed value is only as good as its source.
