PHCP 1.0.0 - Perl Hydraulic Calculation Program

A Hardy Cross loop-balancing hydraulic solver for fire sprinkler and hydrant systems: a plain-text command language for the model (`.phc`), an editor built around it, a calculation report in ASCII text or PDF, and an AutoCAD exporter. Australian units by default (L/min, kPa, m, mm).

## Downloads

| file | what it is |
|---|---|
| `phcp_editor.exe` | the editor: write the model, VALIDATE (F4), CALCULATE (F5), WRITE REPORT (Ctrl+R) |
| `phcp.exe` | the command line: `phcp.exe model.phc report.pdf`, or `phcp.exe --json model.phc` for another program |

Both are self-contained Windows programs with the pipe and fitting database and the report typeface packed inside. The examples are in the source download (`examples/`).

## What is in 1.0

- **The `.phc` command language.** One element per line, fields by position, in any order: `WATER`, `NODE`, `PIPE`, `SPRINKLER`, `HYDRANT`, `HREEL`, `FIXEDFLOW`, `PUMP`, copies and changes (`PC`, `NC`, `CHANGEPIPE`, `EQV`), and devices in a pipe (`BP`, `BFP`, `PRV`, `OPP`, `OFD`, `PRA`). Each quantity can have its own unit. Every error names its line.
- **The editor.**
  - Syntax colours and line numbers.
  - A proposed next line and pick lists.
  - VALIDATE before CALCULATE, listing what is wrong, why, and where.
  - Results tables for pipes, nodes and outlets.
  - Tabs:
    - PROJECT: project details, units and options;
    - GRAPH: hand-made water supply graphs;
    - DATABASE: view and edit the pipe and fitting database, optionally from a shared team folder.
  - Sharp at 125 and 150 % display scaling.
- **The report**, as ASCII text or PDF:
  - a cover sheet;
  - pipe schedules, and node and outlet compliance;
  - the flow path to the governing outlet, worked by hand;
  - supply and demand, with the database's file and SHA-256 recorded.

  The PDF is A4 landscape with an embedded typeface. It draws the supply graph on Q^1.85 paper: a graph per supply when there are several, then all supplies combined.
- **Supply, pump and loss curves** pass through every point entered and are straight between them in Q^1.85.
- **Pressure ratio valves** are designed to the bottom of their +/-5% band, and the top of the band is reported.
- **Fixed flows** have their minimum pressure checked.
- **The GRAPH tab** draws a Q^1.85 water supply graph from figures typed in, independent of any model, and prints it to PDF:
  - A, the supply as measured;
  - B, the loss to the datum;
  - C = A - B;
  - D, a pump;
  - E = C + D;
  - up to ten duty points, each with its margin.

  The figures are saved as a `.phg` file.
- **Other programs.** `phcp.exe --json` returns the results as JSON. The AutoCAD exporter (`autocad/phcp_export.lsp`) writes `.phc` and runs the solve.

## Known limits

- The `.exe` files show the default icon in Explorer. The editor shows the PHCP icon on its window and taskbar button.
- The AutoCAD commands (PHCPEXPORT, PHCPSOLVE) have been checked for structure but not yet run inside AutoCAD.
- A 1000-node gridded network takes several minutes to solve. A design area of a few hundred nodes solves in seconds.
- AS 1074 Medium as the basis bore for AS 2118.1 Table 14.11.1 is an assumption; the Standard does not state one. The database is user-editable, and a changed value is only as good as its source.
